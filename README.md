Привет! Меня зовут Анастасия, я начинающий дата-аналитик, развиваюсь в направлении анализа данных и ищу возможность применить свои знания в своих проектах.

Умею работать с SQL, изучаю Python и его библиотеки, практикуюсь в обработке данных, написании запросов, анализе таблиц и поиске закономерностей в данных. Мне интересно обрабатывать данные, формулировать выводы и преобразовывать таблицы в понятные инсайты для бизнеса.

### Навыки
**SQL:** назначение запросов, фильтрация и сортировка данных, группировка, агрегатные функции, `JOIN`, работа с подзапросами, CTE
**Python:** базовый синтаксис, условия, циклы, функции и другие структуры данных, ООП.

**Pandas:** обработка табличных данных, фильтрация, группировка, агрегация, работа с пропущенными значениями.

**NumPy:** базовая работа с массивами и числовыми данными.

**Matplotlib:** построение простых графиков для анализа данных.

**Математика:** базовые знания теории вероятностей и математической статистики.
