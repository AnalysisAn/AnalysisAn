# Портфолио стажера-аналитика данных
Привет! Меня зовут Анастасия, я начинающий дата-аналитик, развиваюсь в направлении анализа данных и ищу возможность применить свои знания в своих проектах.

Умею работать с SQL, изучаю Python и его библиотеки, практикуюсь в обработке данных, написании запросов, анализе таблиц и поиске закономерностей в данных. Мне интересно обрабатывать данные, формулировать выводы и преобразовывать таблицы в понятные инсайты для бизнеса.

В этом портфолио я собираю технические и практические проекты, которые демонстрируют мой прогресс и умение работать с инструментами для анализа данных.

### Навыки
- **SQL:** назначение запросов, фильтрация и сортировка данных, группировка, агрегатные функции, `JOIN`, работа с подзапросами, CTE
- **Python:** базовый синтаксис, условия, циклы, функции и другие структуры данных, ООП.
- **Pandas:** обработка табличных данных, фильтрация, группировка, агрегация, работа с пропущенными значениями.
- **NumPy:** базовая работа с массивами и числовыми данными.
- **Matplotlib:** построение простых графиков для анализа данных.
- **Математика:** базовые знания теории вероятностей и математической статистики.

### Проекты
#### [1. Анализ клиентской базы банка с помощью Pandas](https://github.com/AnalysisAn/Bank_customers_pandas_analysis)

Учебный EDA-проект, в котором исследуется клиентская база банка: распределение клиентов по странам и возрасту, активность пользователей, баланс и количество используемых банковских продуктов.

***Инструменты:*** Python, Pandas, Matplotlib, Jupyter Notebook

#### [2. Парсинг страницы и анализ данных](https://github.com/AnalysisAn/BeautifulSoup_quotes_parser)

Учебный проект по базовому анализы данных, полученных при парсинге HTML-страницы с помощью BeautifulSoup.

***Инструменты:*** requests, BeautifulSoup, Python, Pandas

#### [3. Анализ рекламных событий](https://github.com/AnalysisAn/Ads_events_analysis)

Учебный проект по анализу логов рекламных событий, выявления причины аномального роста количества взаимодействий в один из дней и дополнительному исследованию данных.

***Инструменты:*** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
